【歪矯正 ver.0.5】 管理者モード・Supabase対応版
================================================

■ このZIPには、サイト本体（index.html / app.js / characters.js / style.css）、
  仮画像 assets/、config.js、追加のSQLファイルがすべて入っています。

■ ファイルについて
  index.html    サイト本体（ブラウザから開く）
  app.js        管理者ログイン・画像管理・画面の動き
  characters.js 接続前のデモデータ（仮画像6人）とサイトタイトル
  style.css     デザイン
  config.js     Supabaseの接続情報（公開可能なものだけ！）
  STEP_11_SQL.sql  一般閲覧者のための画像アクセス設定
  assets/       仮画像18枚＋画像なし表示用

■ 1. SupabaseのSQL Editorで「STEP_11_SQL.sql」を実行する
  これまでStorageはPrivateで、管理者しか画像を読めない設定です。
  この追加SQLは、公開キャラクターに紐づいた画像だけ、
  一般閲覧者にも期限付きURLで見られるようにします。
  バケットをPublicに切り替える必要はありません。

■ 2. config.jsをメモ帳などで開いて、次を設定
  url: "https://xxxx.supabase.co"
  publishableKey: "sb_publishable_xxx"  または従来の anon key
  ※これらはSupabaseのダッシュボードのConnect / API Keysから確認できます。
  ※Database password、service_role、sb_secret_...、管理者パスワードは
    絶対に入れないでください。ChatGPTにも送らないでください。

■ 3. GitHubにZIPの『中身』をアップロードする
  ZIPの中身を解凍します。
  GitHubの該当リポジトリで Add file → Upload files を開き、
  index.html等をリポジトリの一番上の階層に置いてください。
  assets/フォルダもそのまま含めます。ZIP自体だけではWebサイトになりません。

■ 4. ブラウザで確認する
  config.jsが未設定なら、従来どおり仮キャラ6人のデモが表示されます。
  設定を済ませると、Supabaseのデータベースが読み込まれます。
  データが空の場合は、まず管理者ログイン → 編集モードから
  「仮キャラ6人を登録」または「＋ 新しいキャラを追加」を押してください。
  いったんクラウドに登録したら、characters.jsを書き換えても
  クラウドの内容は変わりません。サイト画面から編集してください。

  【重要】GitHub FreeでPrivateリポジトリのままPages公開することは
  できません。一般公開するときはPublicリポジトリに変更して
  Settings → Pages → Deploy from a branch → main / root を指定する
  等の公開設定が必要です。Privateを続ける場合は、ローカルの
  簡易Webサーバー等で動作確認してください。

  例：PCにPythonがある場合
  解凍したフォルダでターミナルを開き、
  python -m http.server 8000
  を実行し、http://localhost:8000/ を開きます。
  ※Pythonが無ければVS CodeのLive Server等でも構いません。

■ 操作方法
  ・ヘッダーの「管理者ログイン」で自分のメールとパスワードを入力
  ・ログイン成功後に編集モードが自動で有効
  ・画像をタップ → スマホのファイルから差し替え（5MB以下）
  ・プロフィール入力欄 → 「変更を保存」
  ・ギャラリー「＋ 画像を追加」 → 画像を登録
  ・ギャラリー画像の「差し替え」「削除」「↑」「↓」「説明」
  ・キャラクターの追加は最初は非公開、公開チェック後に保存
  ・閲覧者には、公開キャラの情報と画像のみが表示されます。
  ・ログアウトすれば編集モードに入れません。
  ・非公開に戻しても既発行の画像URLは最大12時間有効な場合があります。

■ バックアップ
  管理画面の「情報をJSONで保存」は、テキスト・設定・画像パスのみです。
  元画像ファイル自体のバックアップにはなりません。元画像は手元に
  保存してください。自動バックアップ／復元は今後の追加機能です。

■ 注意点
  ・このZIPはSupabase実環境のログイン・保存動作まで検証済みでは
    ありません。実際に設定した後にPCとスマホから確認してください。
  ・管理者ログインしても編集できない場合は、Supabaseで登録した
    ユーザーのUIDがSTEP 8のis_site_admin()に設定されているか確認。
  ・画像のアップロードが失敗する場合はSTEP 10のStorageポリシー、
    登録できるファイル形式／5MBの上限を確認してください。
  ・GitHubのPublicリポジトリ内に置いたファイルは誰でも見られます。
  ・データベース側のRLSが実際の安全性を担います。
